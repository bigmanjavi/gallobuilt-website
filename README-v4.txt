UPLOAD ON IPHONE
1. Extract GalloBuilt-Website-v4.zip in Files.
2. Go to https://github.com/bigmanjavi/gallobuilt-website/upload/main in Safari.
3. Select the SIX website files: index.html, styles-v4.css, script-v4.js, gallobuilt-rooster-logo.png, improvements-level.png, README-v4.txt.
4. Upload and COMMIT to the main branch. Make sure index.html is replaced in the repository root.
5. GitHub > Actions: check that the latest Pages deployment succeeded.
6. Open https://www.gallobuilt.com/?v=4 in a new Private tab to bypass cached homepage.
